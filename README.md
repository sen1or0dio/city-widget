# city-widget

Простой городской сайт на React.

## Запуск

```bash
npm install
npm run dev
```

Команда запускает сразу два проекта:

- фронтенд: `http://localhost:5173`
- бэкенд: `http://localhost:3000`

## Папки

- `src/components` — компоненты сайта
- `public` — картинки и иконки
- `backend` — простой сервер с событиями
